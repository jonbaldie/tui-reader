## Run

From this repository root, run `python3 verification/check_all.py`. It requires Python 3, Go 1.25, mise, Java temurin-25 and TLC 1.7.4. The pinned TLC artifact and checksum are in the runner. A missing dependency fails the command. Each skill explains its bounds and maintenance procedure. Model files remain in the repository, while TLC working directories and scratch source mutations live outside it.

Read each TLA+ result with `/statechart`. Give it the model, adjacent configuration and view module where present. Use a fresh scratch output directory outside the repository. Do not treat an abstract model passing as a proof of the Go implementation. The source checks and mutation demonstrations establish narrower, stated connections to real code.

## Main user flows

The selected flows are inferred from the controls and existing stateful tests. They are not ranked by usage telemetry.

- Opening a file leads to reading, a load-error screen, dump output, or an argument error.
- Selecting and following a link saves its origin for Back.
- Turning pages and resizing must preserve valid current and return positions.
- Quitting closes reading or an error screen.

`charts/startup.mmd` and `charts/reader.mmd` are generated by `/statechart` from Startup and Reader respectively. The startup projection hides option events that stay in Arguments. The reader projection hides Idle and transitions within a visible label. It deliberately merges detailed page, geometry, and history states. The models and raw checker reports retain those distinctions.

## Limits

These are bounded models and finite generated-input checks. No unbounded correctness, liveness, complete Markdown conformance, terminal-library behavior, or operating-system behavior is claimed. Reader resize uses a small abstract source-position map. Its Go check exercises a multi-page fixture separately. Styling models valid span consumption over representative owners and ranges. Its Go fixtures check exact rendered output separately. Startup source checking exhausts a finite argument alphabet; filesystem and process outcomes are abstract in its TLA+ model. Subsystem coverage records state other reductions.
